**Что это значит для Week 3**
- Для «ленивого» ночного сценария — нормально: сводка на ~300 токенов ≈ 2 минуты, а она всё равно идёт без тебя.

**Как ускорить (по эффекту):**
1. Закрыть Chrome — освободит 4.2 ГБ, уберёт своп. Сам не трогаю: скажи — перемерю.
2. `powerprofilesctl set performance` — до 2.5× по частоте (на батарее ест заряд быстрее).
3. qwen2.5:1.5b (~1 ГБ) — примерно вдвое быстрее, для коротких сводок хватает.

**Мелочи:** сервер запущен вручную, без автозапуска — как договаривались. После перезагрузки: `ollama serve`. Удалить всё: `rm -rf ~/.local/opt/ollama ~/.ollama ~/.local/bin/ollama`.

**Про таймер — зачем он:** сам смысл инструмента — работать, когда ты не работаешь. Таймер просто убирает шаг «вспомнить и запустить» — это разница между «инструмент, который ты запускаешь» и «инструмент, который запускается сам». Для челленджа он не обязателен.

Я положил юниты, но **не включал** (автозапуск ты не любишь):
- `~/.config/systemd/user/slothsort.service` — `slothsort ~/Downloads --apply --max 20`, с `Nice=10`;
- `~/.config/systemd/user/slothsort.timer` — каждый день в 03:00.

Проверено: `slothsort.timer` в состоянии **disabled**, в списке таймеров пусто — ничего не запустится само. Если захочешь:
